# Technical note — v4 conditional atmospheric model sensitivity

## Theory
For flat horizontal atmospheric slabs with link height H and zenith z, path length is L=H/cos(z). Each intersected slab contributes its traversed depth divided by cos(z). For printed specific attenuation c_j in dB/km, the integrated attenuation Q=sum(d_j c_j) is in dB; the power ratio is T=10^(-Q/10). The exponential source-reproduction branch uses exp(-Q), equivalent to multiplying the printed coefficient by 10/ln(10) in dB. The distinction is not a correction to the original coefficient values. With independent categorical states, exact joint probabilities are products. E[T] and T(E[Q]) differ by Jensen's inequality; only the stochastic mean is used for mean-power calculations.

Normalized Gaussian irradiance I(x,y)=2/(pi w²) exp[-2((x-r)²+y²)/w²]. A circular receiver radius a captures G=F_ncx2((2a/w)²; df=2, nc=(2r/w)²). Integrating the same irradiance in polar coordinates yields the Bessel formula; Cartesian slices provide an independent numerical check. The Gaussian-equivalent beam radius w=sqrt(w0²+(theta L)²) assumes waist at the transmitter and half-angle divergence. The implied M²=pi w0 theta/lambda is about 2.787 (not measured). For zero-mean independent Gaussian transverse offsets with per-axis SD s=L sigma_theta, R is Rayleigh. With P=Ptx eta T G, define A=P(P>=Pmin). Invert the monotone overlap to find the maximum admissible displacement; conditional success is 1-exp[-rcrit²/(2s²)] for s>0. For s=0 use the deterministic inequality. The zero-offset overlap is 1-exp(-2a²/w²). Averaging G over the pointing distribution gives 1-exp[-a²/(2(s²+w²/4))] by Gaussian convolution.

Weather conditional success is the state-weighted average. For hypothetical prior q, minimize p·A over p>=0, sum p=1 and 0.5||p-q||1<=rho. Sorting and transferring mass from high to low reward solves this finite linear problem; a separately constructed LP checks it. Robust availability is nondecreasing in aperture because each conditional availability is nondecreasing. Therefore feasible-endpoint bisection (not continuous root finding) works even when zero-jitter availability is a step function. Radius is restricted to [0.025,0.50] m. The returned endpoint meets the target, with radius bracket <=1e-7 m unless already feasible at the lower bound.

For finite aperture, Gaussian capture is strictly below 1. A state with Ptx eta T <= Pmin cannot succeed even in perfect alignment. The limit as radius tends to infinity of finite-aperture success uses the strict inequality Ptx eta T > Pmin. Its robust aggregate is a necessary feasibility ceiling; equality with the target alone need not imply a finite feasible receiver. The legacy reference ceiling is 0.964-0.9rho for rho<=0.96; its 92% boundary is rho≈0.048889. This is not a universal threshold. The literal dB and separate fog model can give different ceilings.

## Interpretation
The main branch uses literal dB/km. Separate branches reproduce the disputed equation convention, apply the prose clear-weather layer, and stress-test fog coefficients with a published radiation-fog polynomial. Neither the fog stress case nor the original table is calibrated to local measurements. The code varies targets and priors, but the central physical assumptions remain hypothetical. See SOURCE_MAP.md for provenance and exclusions. Results are optical-power exceedance probabilities, not BER or communications uptime.
